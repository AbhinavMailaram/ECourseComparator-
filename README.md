# Course Comparator

A working Express-based course comparison dashboard.

## Features

- Search courses by title, provider, category, description, or skill.
- Filter by category and level.
- Sort by overall score, rating, price, or duration.
- Select up to three courses for comparison.
- Responsive layout for desktop, tablet, and mobile.
- JSON API endpoints for courses and health checks.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000`.

Health endpoint: `http://localhost:3000/api/health`
